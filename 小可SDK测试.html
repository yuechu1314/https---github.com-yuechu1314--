小可 · Chat SDK 接入测试

这个页面用来验证「智能体发布到 Chat SDK 后能不能直接用」。填好下面两项，点启动，右下角会弹出真正的聊天窗，能正常问答就说明通道打通了。
还没发布？按这三步来：
  1. 扣子 → 打开你的智能体 → 右上角 发布 → 勾选 Chat SDK（建议同时勾选 API，否则拿不到开场白）→ 发布
  2. 在 安装 弹窗里能看到安装代码，里面就有 botId，也可以直接看编排页 URL 里 /bot/ 后面那串
  3. 扣子 → 头像 → 设置 → 个人访问令牌 → 新建令牌，勾上 Bot 对话、会话管理、消息列表等权限，复制出来的 pat_ 就是一串令牌
